# M1–M2 实现与验证说明

日期：2026-11-14。版本：0.1.0。当前交付为 CLI 基础、离线工作流及宿主图像执行协议，尚未执行真实 AI 商品修图。

## 已实现

- Node／TypeScript CLI，严格命令与参数解析，单一 JSON stdout、业务状态、退出码和有来源的错误效果状态。
- SQLite 业务账本、乐观版本校验、步骤进程租约、幂等请求键、事件时间线和可恢复 outbox。
- 原图保留、方向／颜色规范化、不可变 CAS、矩形蒙版与预览、局部合成、保持区检查、实际文件与 hash 验证。
- 需求组保留原文，文字非空且未停用就参与；计划检查覆盖、依赖、循环、输入绑定和区域范围，冻结后不可覆盖。
- 一次授权绑定一个运行、覆盖其已批准步骤；请求未知或取消后，新运行需要新的确认回执。重复请求不会重做已有尝试。
- 默认 host 任务单，一次工具执行意图，真实图片回接、独立语义检查、用户终验与不可覆盖的 exports 交付。交付目录以原子发布的 manifest 作为完成标记。
- 独立演示与正式测试脚本；图像 API fallback 仅保留架构位置，当前不会自动配置、读取密钥或发起独立 API 请求。

## ygl 的两种图

运行图位于业务工作区独占的 ygl home，按冻结计划生成树，每次运行使用独立 context。领域账本先提交真实输入、授权、结果与检查，再通过证据和状态投影同步到 ygl；`node can` 与领域检查共同决定能否继续。手工 unlock 不能替代实际图片与用户接受。

原来的 38 节点能力演进图属于设计与成熟度记录，不是一次图片执行的时间线。本轮实现任务、契约、决策与实际测试依据挂到相应能力节点，成熟度状态没有批量解锁。真实宿主生成、完整质量样本、独立 API 及生产恢复条件仍须分别验收。
