# ADR-002 · 宿主图像能力优先，独立 API 作为显式 fallback

状态：用户方向已确认，M1–M2 实现中。日期：2026-11-14。

## 上下文

用户指出 Codex／ChatGPT 宿主本身提供图像能力，独立图像 API 应成为 fallback。现有 CLI 需要保持可恢复、可核验的领域事实，同时适应不同宿主暴露的工具；当前聊天的工具清单未包含内置图像生成工具。

## 决策

默认计划使用 host 执行器。CLI 持久化任务单和一次执行意图，由宿主调用其实际可用的图像工具，CLI 再回接真实文件。图像收到、局部合成、硬检查、宿主视觉检查与用户终验分开记录。offline 只运行隔离演示；独立 API 适配留作明确选择的 fallback，不自动转换。

在工具调用之前记录未知状态，使接手者不会仅因没看到结果就再次调用模型。同一 request-id 重放返回原回执；`replayed:true` 不能作为再次执行宿主工具的许可。

## 后果

用户可复用宿主的图像功能与额度，CLI 无需要求每个任务先配置独立 API key。代价是宿主与 CLI 之间有一个任务单／实际文件回接协议，工具不可用时会等待，不能宣称所有 Codex／ChatGPT 环境都能由 shell 自动出图。宿主费用或额度仍由宿主管理。

本决策优先于初始方案的提供商接入次序；原始设计捕获与 ygl ID 保留为历史事实。实施与验证按 [宿主协议](HOST-EXECUTOR.md) 和当前路线图推进。
